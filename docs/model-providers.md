# 模型配置与自带知识库

Shiping 自带资料存储、处理队列、向量检索和管理网页。首次安装只需配置模型，无需手工安装 Node、Python、Chroma 或运行后台脚本。SQLite 是软件内部文件，用户无需配置。

## 配置入口

- **设置 → AI 模型**：统一配置对话模型、Embedding 向量模型、Rerank 精排模型。
- **设置 → 资料库**：上传和管理资料；Rerank 只保留启用开关、当前模型和跳转配置入口。
- **资料库 → 打开本机知识库管理与清洗报告**：打开同一个内置后台提供的 Web 界面。端口由软件自动分配，勿固定使用18080。

桌面和网页共用模型、资料及索引。打开 Shiping 会自动启动或连接同数据目录的内置后台，关闭软件会停止自己启动的后台；不会关闭其他应用的进程。资料保存在应用数据目录，升级保留。

## 首次使用

1. 在 AI 模型配置 Embedding：选择平台、填写服务地址、API Key 和模型，测试后保存。云端测试会按平台规则调用计费。
2. 上传 PDF、DOCX、Markdown、TXT 等资料；软件自动解析/OCR、清洗、分段并建立向量索引。
3. 没有配置 Embedding 时也可上传和解析，索引会等待配置；保存模型后自动继续。
4. Rerank 可选。先在 AI 模型配置精排模型，再到资料库启用；未配置时不能开启。
5. 新安装默认使用向量检索；原用户已选择的全文模式设置继续保留。

处理失败会显示原因并允许重试。已完成内容复用向量缓存；更换模型、服务或维度后需要重建索引，避免新旧向量混用。

## 国内云端平台

| 平台 | API 根地址 | Embedding 示例 | Rerank 示例 |
| --- | --- | --- | --- |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `BAAI/bge-m3` | `BAAI/bge-reranker-v2-m3` |
| 阿里云百炼 | 控制台给出的国内业务空间域名，例如 `https://业务空间ID.cn-beijing.maas.aliyuncs.com` | `text-embedding-v4` | `qwen3-rerank` |

到[硅基流动控制台](https://cloud.siliconflow.cn/)或[百炼控制台](https://bailian.console.aliyun.com/)开通所需模型并获取 API Key。Key 与地址的地域/业务空间须匹配。两种模型可分别选择不同平台。

云端 Key 必填，已保存密钥不会回显，留空保留同平台同地址的原密钥。保存配置本身不调用模型；测试、上传后的向量化和检索会向所选平台发送相关文本并按其规则计费。维度检查结果在当前进程复用，避免每次检索重复探测。

硅基流动按任务获取账户模型列表；百炼展示明确标记的推荐模型，实际开通状态以测试为准。列表接口不可用时可手动填写。其他兼容服务分别使用 OpenAI 格式 `/embeddings` 或通用 `/rerank`；私有协议需要单独适配。

Ollama、Xinference 保留为用户自行部署的高级接入，不是新安装必需组件。原固定“本机 BGE Reranker”选项已移除，旧配置自动停用，需重新选择精排提供商。

## 数据与兼容

内置后台保留 SQLite 资料、对话和任务记录，向量也保存于本机 SQLite。现有索引会优先从已校验的缓存迁移，不自动向云平台付费补算；缓存缺失时明确提示重建。旧数据库缺失会报错，禁止用空库掩盖问题。

当前向量检索使用分批、可取消的精确余弦检索，适合个人知识库；尚未对20GB级资料或百万向量规模作性能承诺。遇到向量阶段超时会提供降级诊断。

需要排查时，内置后台的 `runtime.log` 位于资料库数据目录。安装包只带组件和公开资源，不包含开发者API Key、用户资料或本机大型模型。
