# 国内付费向量化与重排接入

用户要求继续增加可购买的国内云端 API 接入。复用已有模型配置架构，直接实施；不购买、不使用真实付费密钥调用。

- 硅基流动：Embedding / Rerank，OpenAI 风格请求；按任务获取模型列表。
- 阿里云百炼：兼容模式 Embedding、DashScope 原生 Rerank；使用控制台提供的国内业务空间域名。提供明确标注的推荐模型列表，实际可用性通过调用测试验证。
- 自定义兼容 Embedding / Rerank：分别配置 Base URL、密钥和模型。保留本机配置。
- 云端 API Key 必填，远端需 HTTPS。留空保留同提供商同地址已保存密钥；模型列表、测试、保存均沿原鉴权和取消边界。
- 云端指纹不依赖 /models，维度探针在同配置下复用，避免每次检索重复收费；维度变化停止查询旧索引。配置保存本身不调用模型。
- UI 告知测试、索引、检索会按平台规则计费并发送相关文本；提供账户/文档链接，保留手动输入。

顺序：失败协议测试 → 后端适配/密钥/指纹 → UI → 本机模拟服务端到端及浏览器检查 → 全量回归/类型/构建/独立审查。

来源：本机 ragflow/conf/models/{siliconflow,aliyun}.json；硅基流动官方 API 文档与阿里云当前 Embedding、文本排序 API 文档。百炼原生接口以当前官方文档为准。
