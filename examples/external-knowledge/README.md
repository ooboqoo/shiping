# 外部知识库 · 接口说明与示例

资料多到不适合每次全文发送时，识屏可以在每次请求前，向你自己运行的知识库服务检索几段资料，随请求一起发给 AI。建库、解析、向量化、精排都由你的服务负责，识屏只管问和用。

设置入口：「设置 → 资料库 → 外部知识库」，填接口地址，勾选用于截图模式 / 对话模式。

## 接口

沿用 [Dify 外部知识库 API](https://docs.dify.ai/en/guides/knowledge-base/external-knowledge-api) 的格式：给 Dify 写过的服务可以直接接上，反过来也一样。

```http
POST {接口地址}/retrieval
Authorization: Bearer {API Key}      # 没填 API Key 时不发
Content-Type: application/json

{
  "knowledge_id": "",                # 「知识库 ID」，没填时为空字符串
  "query": "项目里的缓存是怎么做的",
  "retrieval_setting": { "top_k": 5, "score_threshold": 0 }
}
```

返回 HTTP 200：

```json
{
  "records": [{ "content": "……", "score": 0.82, "title": "简历.md", "metadata": {} }]
}
```

- 按相关度从高到低排好；识屏按顺序取，最多 `top_k` 段、合计 6000 字，`score` 低于阈值的不要（没有 `score` 的照收）
- 没有命中返回 `{ "records": [] }`
- 出错返回非 200，可带 `{ "error_code": 1002, "error_msg": "…" }`，识屏会把 `error_msg` 显示出来

## 识屏用什么去检索

| 场景                       | `query`                                                |
| -------------------------- | ------------------------------------------------------ |
| 截图模式，截图时有语音转录 | 转录的文字                                             |
| 截图模式，追问             | 追问的问题                                             |
| 截图模式，只有截图         | 不检索（没有文字），这一轮不带资料                     |
| 对话模式                   | 这条提示针对的那几句话；太短（不到 20 字）时连上前一句 |

检索到的资料放在这一轮的问题前面，不进系统提示（资料库和场景提示组成的前缀不变，平台可以缓存），也不进对话历史：追问会按新问题重新检索。

## 出问题时

服务连不上、报错或超时（默认 3 秒，可调），这一轮照常作答，只是不带资料，窗口里提示一次（同样的错误一分钟内只提示一次）。请求走「设置 → 网络代理」，本机地址不受影响。

## 示例服务

`server.mjs` 是一个最小实现：把一个文件夹里的 Markdown / TXT 按段切开，按关键词重合度排序。没有依赖，Node 20 以上：

```bash
DOCS=~/my-notes API_KEY=随便一串 node examples/external-knowledge/server.mjs
```

接口地址填 `http://127.0.0.1:8000`，API Key 填同一串。它只是用来跑通和参考的起点：换成向量检索、加精排、接 PDF 解析，接口不用变。
